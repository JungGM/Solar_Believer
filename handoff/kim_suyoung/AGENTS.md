# AI 실행 지침

이 패키지의 유일한 역할은 예보 API 자료를 파일로 수집하고 전달하는 것이다. DB, DataGrip, Docker, 모델 학습, PostgreSQL 설치/연결/적재를 하지 않는다.

1. README_먼저읽기.md를 먼저 읽고 현재 OS와 Python 3.10 이상 여부를 확인한다. Python이 없으면 사용자 환경의 설치 수단으로 설치한다. 추가 pip 패키지는 필요 없다.
2. locations.json의 좌표 및 자원 정보를 그대로 사용한다. 좌표·정확도·변수·기간을 임의로 변경하지 않는다.
3. 사용자에게 충분한 공간이 있는 로컬 저장 경로를 한 번 확인한다. 기존 local_config.json이 있으면 재사용한다. 저장 경로를 코드에 고정하지 않는다.
4. unittest를 실행한다. collector.py --output <경로> --max-requests 1로 실제 응답과 상태를 검증한다. 한도 대기면 기다릴 필요 없이 상태를 보고하고 정상 수집 프로세스로 이어간다.
5. collector.py --output <경로>를 Windows에서는 숨김 백그라운드 프로세스로 실행하고 stdout/stderr를 저장 폴더에 리디렉션한다. 실행 PID와 status.json 갱신을 확인한다. 먼저 같은 폴더의 기존 프로세스를 확인해 중복 실행하지 않는다. 작업 폴더를 현재 패키지 경로로 설정한다. 종료/절전 후 재시작 방법을 사용자에게 알려준다.
6. 기본은 2026년 9월부터 2022년 1월까지 역순 수집이다. 원래 PC와 담당 기간이 합의된 경우에만 --start/--end로 그 범위를 적용한다. 공급자 한도 및 수집기 예산을 높이거나 우회하지 않는다.
7. partial/unavailable은 결측으로 보고한다. 요청 성공과 학습 완성을 구분한다. 실패로 결과를 0으로 채우지 않는다.
8. 결과 전달 시 수집기를 정상 종료하고 export_results.py로 검증·분할 압축한다. 사용자가 업로드를 요청하면 팀 저장소/브랜치를 확인한 후 생성된 결과 ZIP과 manifest.json만 커밋/푸시한다. 인증키·환경파일·개인 설정은 포함하지 않는다. 무관한 변경을 커밋하지 않는다.
9. DB에 넣는 작업은 받는 사람이 수행한다. 데이터만 수집하면 이 PC의 역할은 끝이다.
