# 정산 규칙 참고와 개별 발전기 평가

> **2026-11-27 현재 범위:** [개별 발전기 사후 모의정산 계약](INDIVIDUAL_SETTLEMENT_DIRECTION.md)을 따른다.
> 발전기별로 같은 실제 발전량·SMP 조건의 최대·최소 가능 금액과 사후 모의정산금을 비교하고,
> 미획득 인센티브·획득률을 평가한다. VPP 구성·그룹 비교는 이번 범위에서 제외한다.
> 수 kW급 적용은 연구용 가상 인센티브이며 실제 개별자원 참여 자격과 구분한다.
> 아래 VPP 중심 명세는 규칙 조사와 종전 설계의 역사 기록이다. 새 구현은 데스크톱에서 진행할 후속 작업이다.

기준일: 2026-11-19 KST. **구현 예정**. 현재 `UnconfiguredSettlementRule`은 금액을 계산하지 않는다.
이 문서는 태양광만으로 구성한 자원의 1시간 거래 구간을 우선 다룬다.
공개 원천을 이용한 연구용 계산이며 실제 지급 정산명세로 표시하지 않는다.

당시 실제 제도를 재현하려면 시행일별 규칙 버전을 따로 적용한다. 2022년부터의 실수령액으로 표시하지 않는다.
제주 입찰제도·다른 시장 정산 전체를 이 예측제도 인센티브 식으로 대체하지 않는다.

## 1. 자원·시간·입력

예측형 집합전력자원의 주요자원 용량 조건은 **20MW 초과**다.
‘정확히 20MW’, ‘20MW 이하’, ‘발전기 200개 이상’이 해당 제도의 용량 조건이라는 설명은 잘못이다.
최소 2개 그룹 구성은 각 그룹 용량·구성 자격·등록시험 등을 별도로 확인해야 한다.
63MW 발전기 한 개를 가상의 소규모 자원 여러 개로 나누지 않는다.

시간 t의 VPP 구성원은 해당 구간에 유효한 구성 버전으로 고정하고 먼저 합산한다.
같은 발전기를 같은 시간의 서로 다른 비교 대상 VPP에 중복 배치하지 않는다.
발전량은 공식 정산용 전력거래량과 의미가 같은지 확인한다. 발전단/인버터 실측은 다를 수 있다.
다음 단위는 내부 표준 제안이며, API 원천 단위는 변환 근거를 보존한다.

| 기호 | 뜻 | 내부 단위 |
|---|---|---|
| C(t) | 평가 대상 태양광 설비용량 합계 | kW |
| A(t) | 동일 자원의 해당 구간 실제 전력거래량 합계 | kWh |
| P1(t), P2(t) | 두 제출 차수에 해당하는 유효 예측 합계 | kWh |
| S(t) | 대상 지역·구간 SMP | 원/kWh |
| Δt | 거래 구간 길이 | 1시간 |

출력제어 제외·이용률 판정을 적용한 자원/전력량에 대해 계산한다.
육지/제주와 구간 시작/끝 시각을 섞지 않는다. 없는 실측·예측·가격을 0으로 채우지 않는다.
현재 코드가 추정한 `available_at`을 가격/실측의 실제 발표시각으로 간주하지 않는다.

## 2. SMP 기준 판매금액 추정

```text
구간 판매금액 추정 = A(t) × S(t)
기간 판매금액 추정 = 유효한 구간별 금액의 합
```

이는 SMP 기준 참고금액이다. 계약가격·REC·수수료·손실계수·기타 정산 조정은 포함하지 않는다.
미래 금액은 당시 알려진 가격이나 명시한 가격 가정을 써서 예상치로 표시하고,
사후 실제 SMP를 사용한 금액과 구분한다. SMP는 발전기 수만큼 중복 호출하지 않고 육지/제주별로 공유한다.

## 3. 예측제도 인센티브

다음은 **태양광만, 보조자원 없음, 1시간 구간, 필요한 제외처리 완료** 조건의 이해용 식이다.
생산 구현은 공식 별표2의 주요/보조자원·유효성 플래그와 별표8의 반올림 기준을 따른다.

```text
구간 설비이용률(%) = A(t) / (C(t) × Δt) × 100
1차 오차율(%) = |P1(t) - A(t)| / (C(t) × Δt) × 100
2차 오차율(%) = |P2(t) - A(t)| / (C(t) × Δt) × 100
평균 예측오차율 FER(%) = (1차 오차율 + 2차 오차율) / 2
```

예측값을 먼저 평균한 뒤 절대오차를 계산하면 두 차수의 반대 방향 오차가 상쇄되므로 위 식과 다르다.
개별 발전기의 절대오차를 더하는 방식도 VPP 합산 후 평가와 다르다. 실제 발전량을 분모로 쓰는 MAPE가 아니다.

| FER | 기준 단가 |
|---|---:|
| 4% 이하 | 4원/kWh |
| 4% 초과~6% 이하 | 3원/kWh |
| 6% 초과 | 0원/kWh |

설비이용률 10% 이상인 유효 시간대의 대상 전력거래량에 단가를 적용한다.
원문의 MWh에 곱하는 1,000은 위 kWh 내부 표준으로 변환했다면 다시 곱하지 않는다.

```text
구간 예측제도 정산금 = 정산 대상 전력거래량(kWh) × 단가(원/kWh) × 적용계수
```

육지 예측제도 자원의 적용계수는 1이다. 규칙은 제주 시범사업의 재생에너지 입찰제도와
예측제도에 동시 참여하는 자원에 0.5를 정한다. 제주 전체에 일괄 적용하지 말고 참여 유형을 확인한다.
유효성·출력제어·일시적 용량 변동·소수점 처리·등록 조건을 반영하기 전에는 공식 지급액과 같다고 주장하지 않는다.

거래전일 1차 10시·2차 17시 제출, 각각 14시·20시까지 변경 가능하다는 규칙에 맞춰
두 차수의 cutoff·유효 예측·변경 이력을 보존한다. 예보를 8회 수집하는 일정과 제출 차수는 다르다.
우리 서비스에서 만든 예측을 공식 제출 예측으로 표시하지 않는다. 한 차수 누락을 임의 복제해 채우지 않는다.

## 4. 손실·웹 표시·DB 저장

- ‘발전량 절대오차(kWh)’, ‘SMP 기준 판매금액 추정(원)’, ‘예측제도 인센티브 시뮬레이션(원)’을 구분한다.
- ‘미획득 인센티브’는 동일 정산 대상 전력량·적용계수에서 최고 단가를 적용한 참고금액과의 차이로 정의한다.
  실제 벌금·청구금·확정 손실이 아니다. `|예측-실측| × SMP`를 공식 패널티로 사용하지 않는다.
- 현재 `vpp_settlements` 등 저장 구조를 검토해 규칙 버전·대상 기간·VPP 구성 버전·모델 버전·
  두 제출 차수·원천 개정 버전·단위·cutoff·제외 사유·가격 구역·시뮬레이션 여부를 보존한다.
  현재 schema에 없는 필드는 새 migration 또는 명시적인 details 계약으로 추가한다.
- DB 기록이 없는 금액은 미설정/집계 불가로 표시한다. 누락 구간이 있는 기간의 일부 금액을 완전한 월 정산으로 표시하지 않는다.
- 실제 지급 정산금 조회는 사업자 권한이 있는 공식 명세를 별도 연동해야 한다.
