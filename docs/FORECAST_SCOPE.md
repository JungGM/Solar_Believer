# 태양광 발전량 예측 중심 목표

확정일: **2026-11-23 KST**. 이 문서는 이전 문서의 VPP·정산 중심 목표보다 우선한다.

## 목표와 범위

프로젝트의 목표는 **확보 가능한 개별 태양광 발전소의 시간별 발전량 예측과 정확도 검증**이다.
사용자 결정에 따라 VPP 구성은 목표에서 제외한다. VPP 그룹 수·용량 요건과 발전기 200개 확보를 예측 개발의 선행 조건으로 삼지 않는다.
SMP·정산 시뮬레이션은 현재 예측 개발의 필수 산출물에서 제외한다.
기존 수집 자료·코드·DB·VPP 관련 구현은 보존하며, 이번 변경은 목표와 작업 우선순위를 문서화하는 것이다.
수집기 실행, 실행 설정 변경, 모델 학습 또는 서비스 배포를 지시하거나 수행하는 변경은 아니다.

## 최신 발전 실측이 부족한 상황에서의 개발 방향

최신 발전량 자료가 부족하다는 사용자 판단을 반영한다. 공급처별 최신 제공 날짜나 지연 일수는 이번 문서 변경에서 새로 검증한 값이 아니다.

1. 발전소별 실측의 시작·종료일, 결측률, 시간 간격, 단위, 위치·용량의 확인 여부를 정리한다. 최근 자료 부족과 과거 자료 부족을 구분한다.
2. 발전 실측과 기상 자료가 겹치는 과거 기간에서 품질이 확인되는 발전소부터 예측 대상으로 선정한다. 발전소 수 확대보다 학습·검증 가능한 데이터셋 확보를 우선한다.
3. 학습·검증·시험 기간을 시간 순으로 분리한다. 미래 관측 기상이나 예측 시점에 알 수 없던 정보를 입력하지 않는다.
4. 전일 동일 시간 발전량 등 단순 기준 모델과 예측 모델을 같은 시험 기간에서 비교한다. MAE·RMSE, 주간 시간대 오차와 평가 표본 수를 기록한다. 용량 기준 정규화 지표는 설비용량이 검증된 경우에만 쓴다.
5. 발전소별 예측·실측·오차와 데이터 기준일을 웹에 표시한다. 과거 검증 결과와 최신 날짜의 예측 결과를 구분한다.

과거 예보를 쓰는 하루 전 예측 검증에서는 발표시각과 대상시각을 확인한다.
과거 예보가 사후 수집된 경우 당시 실제 입수 이력을 확인한 운영 검증과 구분해 과거 모의 검증으로 기록한다.
관측 기상만으로 수행한 실험은 관측 기반 추정으로 표시하고, 하루 전 예보 기반 성능으로 보고하지 않는다.
누락 실측을 0으로 채우거나 지역 집계 발전량을 개별 발전소 실측으로 임의 분할하지 않는다.

## 완료 기준과 한계

- 대상 발전소·데이터 기간·단위·결측 처리와 기상 매핑 근거가 정리되어 있다.
- 시간 순 시험 구간에서 기준 모델과 예측 모델의 오차를 재현할 수 있다.
- 예측 결과에 예측 기준시각·대상시각·모델 버전·실측 확보 여부를 남긴다.
- 웹에서 발전소별 예측·실측·오차와 데이터 최신성을 확인할 수 있다.

과거 실측으로 예측 모델을 개발하고 검증할 수는 있지만, 최신 실측이 없으면 최근 운영 성능은 평가할 수 없다.
최신 실측 확보와 운영 평가는 이후 별도 과제로 두며, 과거 검증 완료를 실시간 운영 검증 완료로 표시하지 않는다.
