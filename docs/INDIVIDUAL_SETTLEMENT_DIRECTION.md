# 개별 발전기 사후 모의정산 평가 방향

결정일: **2026-11-27 KST**. 사용자와 합의한 현재 프로젝트 범위이며, 기존 VPP 중심 계획보다 우선한다.
후속 개발·학습·웹 통합은 **메인 데스크톱에서 진행**한다. 이번 변경은 방향과 계산·화면 계약을 기록한
문서 변경이다. 모델 생성·학습, 정산 엔진 구현, 웹 개편, 수집기 실행이나 DB 변경을 완료한 것이 아니다.

## 1. 변경한 목표

개별 발전량이 지속적으로 들어오지 않는 자원이 있어, 여러 발전기의 동시 자료를 요구하는 VPP 구성과
그룹 비교를 이번 프로젝트 범위에서 제외한다. 발전기마다 확보되는 자료와 평가 가능 기간을 확인하고,
**개별 발전기의 예측 오차가 모의 인센티브와 사후 모의정산금에 미치는 영향**을 웹에서 평가한다.

```text
개별 발전기 선택
  → 같은 시간의 실제 발전량·유효 용량·두 차수 예측·SMP 연결
  → 시간별 예측 오차율과 가상 인센티브 계산
  → 발전기별 사후 모의정산금 산출
  → 동일 조건의 최대·최소 금액, 미획득 인센티브·획득률 비교
```

- VPP 구성·최적화, 그룹 합산 오차, 최소 2개 그룹과 그룹별 용량 충족은 새 화면의 목표가 아니다.
- 200개 발전기 확보를 개별 평가의 시작 조건으로 두지 않는다. 자료가 충분한 발전기부터 평가한다.
- 시도 합계 발전량을 개별 발전기처럼 표시하거나 임의 분할하지 않는다.
- 기존 VPP 코드·테이블·기록은 이 결정만으로 삭제하지 않는다. 후속 웹 개편에서 사용자 진입점과
  기본 조회를 개별 발전기 중심으로 전환한다.
- 수집 중단·지연·결측은 발전기별로 표시한다. 다른 발전기의 누락 때문에 정상 자원의 평가까지 막지 않는다.

## 2. 이번에 채택할 정산 범위

주 평가 방식은 **육지 태양광, 보조자원 없음, 1시간 구간**에 대한 예측제도 모의정산이다.
소규모 개별 발전기에도 연구용으로 같은 오차율·단가 규칙을 가상 적용할 수 있다.
실제 예측제도의 개별자원 참여 조건은 설비용량 **20MW 초과와 등록·검증 조건 충족**이므로,
수 kW급 계산을 공식 지급액이나 실제 제도 참여로 표시하지 않는다.

제주 하루전·실시간 시장의 편차 정산과 EMS 급전지시 기준 임밸런스 페널티는 별도 제도다.
이번 화면의 기본 평가식에 섞지 않는다. 해당 기능이 필요해질 때 확정계획량·급전지시·구간 가격 등
별도 입력과 참여 조건을 확보한 뒤 범위를 정한다.

## 3. 발전기별 시간 단위 입력

| 값 | 용도와 조건 |
|---|---|
| 발전기 ID, 거래일, 구간 시작·끝, 시간대 | 같은 자원·같은 물리 구간 연결. 내부 시간대는 KST를 명시 |
| 실제 발전량 A(t), kWh | 관측값과 원천·개정 버전. 공식 전력거래량과 계량 기준이 같은지 별도 확인 |
| 유효 설비용량 C(t), kW | 고장·정비·변경 이력 반영. 미확인 용량을 기본값으로 채우지 않음 |
| 1차 예측 P1(t), 2차 예측 P2(t), kWh | 각각의 모델 버전, 입력 cutoff, 생성·제출·수정 시각 보존 |
| SMP S(t), 원/kWh | 자원의 가격 구역 및 동일 거래 구간. 사후 계산에는 당시 실제 가격 사용 |
| 출력제어·제외 여부, 데이터 품질 | 알려진 제외와 정보 미확인을 구분. 미확인을 '출력제어 없음'으로 바꾸지 않음 |
| 규칙 버전·단위·시각 변환 근거 | 과거 자료에 현재 규칙을 적용한 실험인지 당시 규칙 재현인지 표시 |

두 차수는 거래전일 10시·17시 기준이며, 규칙상 허용되는 변경은 각각 14시·20시까지다.
초기 제출·수정·각 시점에 이용 가능했던 정보 이력을 보존한다. 기존 웹의 전일 18시 비교 정책을
그대로 공식 두 차수 정책으로 간주하지 않는다. 한 차수 누락을 다른 차수 예측으로 임의 복제하지 않는다.
공식 이전 제출값 인정 규정을 재현하려면 실제 제출 이력과 차수별 유효값 선택을 별도로 구현한다.

## 4. 시간별 계산과 최대·최소 비교

다음 식은 육지 태양광 단일 자원, 보조자원 없음, 제외처리 후 유효 시간에 대한 식이다.
원천 단위와 공식 반올림을 적용한 값을 사용한다. 시간 길이 Δt는 1시간이다.

```text
설비이용률(%) = A(t) / (C(t) × Δt) × 100
1차 오차율(%) = |P1(t) - A(t)| / (C(t) × Δt) × 100
2차 오차율(%) = |P2(t) - A(t)| / (C(t) × Δt) × 100
평균 오차율 FER(t) = (1차 오차율 + 2차 오차율) / 2
```

두 예측값을 먼저 평균한 뒤 절대오차를 구하지 않는다. 일평균 오차로 하루 전체의 단가를 결정하지 않는다.
시간별 설비이용률 10% 이상인 평가 대상 구간에 다음 단가를 적용한다.

| 시간별 두 차수 평균 오차율 | 단가 r(t) |
|---|---:|
| 4% 이하 | 4원/kWh |
| 4% 초과~6% 이하 | 3원/kWh |
| 6% 초과 | 0원/kWh |

```text
B(t) = A(t) × S(t)                         # SMP 기준 판매금액 참고치
I(t) = 평가 대상 발전량 × r(t)             # 모델 예측에 따른 가상 인센티브
Imax(t) = 평가 대상 발전량 × 4원/kWh       # 같은 조건의 최대 인센티브
Imin(t) = 0                               # 같은 조건의 최소 인센티브

사후 모의정산금 R(t) = B(t) + I(t)
최대 가능 모의정산금 Rmax(t) = B(t) + Imax(t)
최소 가능 모의정산금 Rmin(t) = B(t) + Imin(t)
미획득 인센티브 L(t) = Imax(t) - I(t) = Rmax(t) - R(t)
```

최대·최소는 **동일한 실제 발전량·실제 SMP·유효 용량·평가 구간·제외 정책**을 고정하고,
오차율에 따른 인센티브만 바꾼 범위다. 미래 발전량·전력가격의 상하한이나 확률 예측구간이 아니다.
설비이용률 미달 또는 알려진 제외 시간은 최대 인센티브에도 넣지 않는다. 알 수 없는 제외 상태는 미확인으로 남긴다.

판매금액 참고치는 REC·계약가격·수수료·세금·손실계수·기타 정산 조정을 포함하지 않는다.
가격이 음수이면 그 부호를 보존한다. 인센티브 최소가 0이라는 이유로 판매금액까지 0으로 자르지 않는다.
`|예측 - 실측| × SMP` 또는 대회 전용 계수를 별도 공식 벌금으로 차감하지 않는다.

기간 합계는 시간별로 단가·금액을 계산한 뒤 더한다. 모델 비교와 세 금액의 비교에는 같은 유효 시간 집합을 쓴다.
관측·가격·용량·예측이 누락된 시간을 0으로 채우지 않으며, 계산 가능 시간 수와 누락·제외 사유를 함께 표시한다.
모델 예측 누락 시 사후 결과는 미산정으로 두고, 별도로 계산한 최대·최소 노출액을 완전한 비교로 표시하지 않는다.

인센티브 획득률은 기간 합계로 다음과 같이 계산한다.

```text
획득률(%) = Σ I(t) / Σ Imax(t) × 100
           = (Σ R(t) - Σ Rmin(t)) / (Σ Rmax(t) - Σ Rmin(t)) × 100
```

분모가 0이면 획득률은 미표시한다. `사후 모의정산금 / 최대 가능 모의정산금`은 판매금액이 비중을
지배하므로 모델의 인센티브 획득 성능 지표로 쓰지 않는다.

## 5. 소규모 발전기 하루 예시

아래 발전량·가격·예측은 모두 설명용 가정이다. 실제 데이터나 공식 지급 결과가 아니다.
10kW 설비, 발전량이 발생한 8개 구간, 제외·고장 없음, 각 구간의 설비이용률 10% 이상을 가정한다.

| 구간 | 실제 kWh | 1차 예측 kWh | 2차 예측 kWh | 평균 오차율 | SMP 원/kWh | 판매금액 원 | 인센티브 원 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 09~10시 | 2 | 2 | 2 | 0% | 100 | 200 | 8 |
| 10~11시 | 4 | 4 | 4 | 0% | 110 | 440 | 16 |
| 11~12시 | 6 | 7 | 6 | 5% | 120 | 720 | 18 |
| 12~13시 | 8 | 9 | 9 | 10% | 110 | 880 | 0 |
| 13~14시 | 8 | 9 | 8 | 5% | 100 | 800 | 24 |
| 14~15시 | 6 | 7 | 6 | 5% | 110 | 660 | 18 |
| 15~16시 | 4 | 4 | 4 | 0% | 130 | 520 | 16 |
| 16~17시 | 2 | 2 | 2 | 0% | 140 | 280 | 8 |
| 합계 | 40 |  |  |  |  | 4,500 | 108 |

| 평가 금액 | 결과 |
|---|---:|
| 최대 인센티브 | 160원 |
| 최소 가능 모의정산금 | 4,500원 |
| 해당 모델의 사후 모의정산금 | 4,608원 |
| 최대 가능 모의정산금 | 4,660원 |
| 미획득 인센티브 | 52원 |
| 인센티브 획득률 | 67.5% |

별표8에 따라 예측제도 용량은 MW 소수 셋째자리(kW), 예측·실제 전력량은 MWh 소수 셋째자리(kWh),
오차율·이용률은 % 소수 셋째자리까지 반올림하며 시간별 정산금은 원 단위로 반올림한다.
수 kW급에서는 kWh 반올림이 오차율을 크게 바꾸므로, 반올림 전 모델 정확도와 규칙 적용 결과를 함께 보존한다.
차수별 중간값을 포함한 계산 순서와 경계 반올림은 엔진 구현 시 규칙 대조 검증 항목이다.
위 예시 합계는 시간별 모의 금액의 합이며, 별표8의 최종 청구금액 10원 미만 절사까지 적용한 청구서가 아니다.

## 6. 예상 금액과 사후 결과의 구분

| 화면 용어 | 의미 | 이번 방향에서의 처리 |
|---|---|---|
| 예상 판매금액 | 예측 발전량 × 예측 시점에 공개된 가격 또는 명시적 가격 가정 | 가격 기준·예측 생성 시각을 표시 |
| 예상 인센티브·예상 정산금 | 미래 실제량과 예측 오차까지 고려한 기대값 | 과거 시간순 검증 오차와 보정 근거가 없으면 미산정. 최고 단가를 자동 부여하지 않음 |
| 사후 모의정산금 | 실제 발전량·실제 SMP와 당시 두 차수 예측으로 계산한 결과 | 이번 웹의 핵심 평가값 |
| 최대·최소 가능 모의정산금 | 같은 사후 실측·가격 조건에서 인센티브만 바꾼 비교값 | 사후 결과와 같은 구간에서 비교 |
| 공식 지급액 | 사업자 계약·참여 자격·최종 정산명세에 따른 금액 | 현재 공개자료 계산으로 대체하지 않음 |

## 7. 웹 개편 목표

기본 필터는 **발전기 → 기간(일/월/연) → 모델 버전 → 규칙 버전**으로 구성한다.
VPP 선택·구성·그룹 성과를 주 흐름에서 제외하고, 개별 발전기별로 아래 항목을 보여준다.

- 요약: 실제 발전량, SMP 판매금액 참고치, 최대·최소 가능 모의정산금, 사후 모의정산금,
  미획득 인센티브, 인센티브 획득률, 계산 가능 시간/대상 시간.
- 시계열: 두 차수 예측과 실제 발전량, 용량 대비 오차율, 4%·6% 기준, SMP,
  시간별 인센티브·미획득액. 서로 다른 단위는 축·범례로 분리한다.
- 상세 표: 구간, 원천 실제값, 용량, 두 예측과 cutoff, 평가 제외 여부, 단가, 계산 금액, 누락 사유.
- 모델 비교: 같은 발전기·같은 실제값·같은 시간·같은 규칙에서 MAE와 인센티브 획득률·미획득액 비교.
- 발전기 비교: 자원별 결과를 각각 표시한다. 서로 다른 평가기간·확보율·용량의 금액을 단순 성능 순위로 해석하지 않는다.
- 자료가 없으면 미산정/부분 평가/제외 사유를 표시한다. 결과가 없는 상태를 0원 수령으로 표시하지 않는다.

공식 정산처럼 보이는 가짜 실수령액을 만들지 않는다. 설명용 예시는 예시, 사용자 데이터 계산은 사후 모의정산으로 표시한다.

## 9. 데스크톱 후속 작업과 완료 조건

1. 데스크톱 체크아웃의 최신 Git 기록을 확인하고 이 문서를 먼저 읽는다. 로컬 변경을 덮어쓰지 않는다.
   이 문서 작성으로 수집 PC·DB 접속·프로세스 설정을 변경하지 않았다.
2. 개별 자원의 실측 연속성·단위·구간·용량·기상 매핑을 점검하고, 평가 가능한 발전기와 기간을 확정한다.
3. 모델 개발 요청을 받은 단계에서 시점별 예측과 시간순 검증을 구현한다. 이번 기록은 학습 실행 지시가 아니다.
4. 두 예측 차수의 입력·생성 이력과 규칙 버전을 연결하고, 개별 시간별 모의정산 엔진을 구현한다.
5. 4%·6%·이용률 10% 경계, 반대 방향 차수 오차, 소규모 반올림, 가격/실측/예측 누락,
   출력제어·용량 변경, KST 자정, 음수 가격, 원천 개정 후 재계산을 검증한다.
6. 같은 시간 집합에서 `Rmin ≤ R ≤ Rmax`, 미획득액 비음수, 획득률 분모 0 처리와 예시 재계산을 확인한다.
7. 개별 발전기 중심 화면을 연결하고, 부분 기간·미산정·모의 표시 및 모델 비교를 확인한다.
